Client login

Client email/password login and CSV download run on the private local API for now (not on sciscore.com). After sign-in, clients can download their org-scoped CSV; non-OA content will unlock in the same place once ingested.

  1. Add a user in the private repo:
    python3 scripts/manage_client_users.py add --email you@org.org --org-id AACR
  2. Start the API:
    python3 scripts/client_api_server.py
  3. Open the login + download page:
    http://127.0.0.1:8787/clients/login
Open local login Back to dashboard

Public GitHub Pages stays OA-only. Authenticated download requires the local API session.
