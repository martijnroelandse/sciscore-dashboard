Client login

Temporary Phase 2 client access lives with this GitHub-hosted dashboard flow. There is no client login on sciscore.com yet.

  1. In the private repo, start the local API:
    python3 scripts/client_api_server.py
  2. Open the interactive login UI at
    http://127.0.0.1:8787/clients/login
  3. Sign in with your passcode from auth_config.json (private local config).
Open local login Back to dashboard

Public Pages remains OA-only. Authenticated metrics/export use private client CSV ingest + the local API. ORCID / sciscore.com portal comes later.
