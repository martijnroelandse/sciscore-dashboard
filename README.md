# SciScore Journal Intelligence — public OA demo

This repository contains **built artifacts only** for the public GitHub Pages demo. Source code, raw data, and build scripts live in the private `sciscore-dashboard-private` repository.

**Live demo:** https://martijnroelandse.github.io/sciscore-dashboard/SciScore_journal_dashboard.html

## What this is

- Interactive dashboard of **rigor and transparency (RTI) metrics** for biomedical journals
- Based on the **PubMed Central open-access subset** only
- Includes all publishers and journals in the OA corpus (including AACR titles)

## What this is not

- **Not** the full publisher corpus (non-open-access articles are excluded)
- **Not** for redistribution — metrics are © SciScore / SciCrunch Inc.
- **Not** a source repo — do not open PRs here for feature work

## Export

CSV and PowerPoint export require **SciScore client sign-in** (e.g. AACR full-corpus access). Contact [SciScore](https://sciscore.com) for client access.

## Methodology

See [addendum.html](addendum.html) for metric definitions, limitations, and references.

## Data limitations

The open-access subset underrepresents journals with restrictive access policies. Compare metrics across journals with care and always note paper counts.
